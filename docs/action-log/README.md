# Action Log

This folder is the append-only record of completed features and fixes. Each
note is generated by `dart tool/change_harness.dart --record` and should be
completed with the change summary and validation results. Do not edit or
replace an older action note to make it represent a different change.

No Git repository is currently initialized in `projects/vaniawatch`, so
these notes are local files rather than committed history. Initialize or
attach the intended repository before relying on Git as the durable audit
trail.
